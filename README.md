# 石头记

开发中，当前为阶段性实现；公开仓库用于保存项目和继续协作。

林黛玉视角的春日庭院游戏，当前包含潇湘馆、怡红院、蘅芜苑的庭院与内室，以及10位NPC的往来、对话和原著片段。

公开仓库：[STHONEONE/shitouji](https://github.com/STHONEONE/shitouji)。GitHub未保留纯中文仓库名，采用`shitouji`；项目中文名称为《石头记》。

## 下载与运行

游戏是离线单文件HTML，电脑浏览器直接打开`outputs/潇湘馆-庭院与内室-模块03.html`即可。无需服务器或联网加载图片，琴音由浏览器合成。

**当前HTML超过GitHub普通Git的100MiB限制，仓库用Git LFS保存。**先安装Git LFS，再克隆：

```sh
git lfs install
git clone https://github.com/STHONEONE/shitouji.git
cd shitouji
git lfs pull
```

请确认游戏文件约111MiB，文件开头为HTML；若只有三行`version https://git-lfs.github.com/spec/v1`，说明尚未取得LFS实体，先运行`git lfs pull`。不要将网页上的LFS指针当成游戏。官方说明：[GitHub大文件与Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。

本地存档保存在浏览器中；继续原存档时保持入口的原位置和文件名。整理保留了现有入口及存档键。

## 操作

- WASD / 方向键移动，Shift 疾走。
- 靠近物件按 E 打开互动；F 在庭院拾花、在室内调查。
- H 心语，J 手札，P 保存，Esc 收起当前对话。
- 右侧 ＋／− 或键盘 ＋／−：100%、75%、50% 三档；点击倍率回到 100%。
- 默认“适配”会根据浏览器可用画幅选择原有三档之一。手动调整倍率后保留手动选择；点击右侧“适配”可恢复自动适配。游戏区随浏览器可用高度变化，不再固定为 600px 横长框。
- 右侧“住所”选择潇湘馆、怡红院或蘅芜苑；再次前往会记住上次离开位置。正房门口 E 进出，出门返回入门时位置与朝向。
- “住所”旁的“潇／怡／蘅”图标可以直接前往，数字键 1／2／3 对应同样的三个住所。切换有短淡入淡出，到达后淡显住所名；过渡期间暂停行走输入。
- 手札可读诗笺、翻图鉴、小憩；抚琴、写诗、品茶可在对应物件处进行。
- 室内南门与庭院正房门口按 E 往返，月洞门外仍封闭。

## 春日与花事

农历日期和时辰常驻显示。本篇只呈现春日，日期在农历三月循环。自然停留会缓慢推进时辰；对话和阅读界面暂停自然流逝，读完诗笺、小憩、抚琴会推进时辰。

每天未、申时的花事在花坛边自然展开，酉时收束。可以参与拾花、掘土、读诗，也可看完整段、只拾花或去做其他事。不同经历会留在心语中，诗笺仍可随时重读，活动之间没有任务前置。

《葬花吟》《咏白海棠》《题帕三绝》为原著诗文。写诗选项为本篇原创意境选句，界面已区分。琴音使用 Web Audio 合成拨弦声，无对错判定。

## 存档

位置、落花、五类图鉴、心语记录、花事状态、农历日期和时辰共同保存到当前浏览器的 localStorage。可手动保存，也会在活动后、场景切换时和游玩期间自动保存。题页有继续与新游戏入口；覆盖旧档前需要确认。

换浏览器或清除浏览器数据会丢失本地存档。为继续读取同一文件的存档，请保持 HTML 的位置和文件名。

住所当前位置、各住所上次位置、房门返回点和缩放档位保存在原存档的 extensions 中，时间、收集和原玩法存档共用。旧存档自动按潇湘馆读取；若旧位置在当前关闭的园路上，会回到庭院安全落点。切换住所不会推进时辰或清空收集。
