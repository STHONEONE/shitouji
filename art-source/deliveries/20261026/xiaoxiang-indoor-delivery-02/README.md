# 潇湘馆内室：第二批素材（待对位与验收）

本包仅包含六项本轮新生成的地面/墙体组件，以及**唯一一张旧版蓝白床榻**。

## 床的处理
`occluders/bed.png` 使用之前从已确认室内母图提取的 **332×279 PNG 原版床榻**。
本轮重新设计的 `中式古典帷帐榻床像.png` 与已确认母图造型不一致，**未纳入**压缩包；不允许用它覆盖原床。旧版床的边缘仍需要美术人工核验。

## 墙体与地板状态
六张新素材虽然均带真实 Alpha，但它们是独立生成的稿件。部分墙体宽度/尺度、转角和入口墙段，与已确认的 1672×941 场景母图**尚未严格对位**；`floor.png` 的地板外轮廓也不应在验证前视作确定地面形状。
**请勿直接用于替换正式场景贴图**，也不要通过非等比拉伸来掩盖尺度差异。后续应依母图精确核对或重做这些墙/地面素材。

`manifest.json` 提供素材名称、尺寸及来源。此包中每项只保留一张，不含替代候选版。没有编造 placement 坐标。
