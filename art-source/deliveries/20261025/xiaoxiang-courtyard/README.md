# 潇湘馆庭院｜首批透明对象（仅供审核）

来源是用户本轮上传的 `xiaoxiang-courtyard-wide.png`（1671×941）。同一母版裁切，PNG 与无损 WebP 各一套，每个 `id` 唯一、没有同一座建筑的两种候选图。`main-house` 唯一，院墙分别为 `wall-side-left`、`wall-gate`、`wall-side-right` 三个不同位置的组成件，接缝 x=645、x=1014。

## 当前包含

唯一正房 1 件、院墙连月洞门 3 段、茶具石桌 1 件、4 个石凳、台阶两侧石灯 2 件，共 11 件不同对象。石凳相互独立。全体维持参考图原始像素大小和原位。真 Alpha 像素与 PNG/WebP 一致性检查见 `alpha-audit.json`。

## **尚不可作为正式入库图**

原参考图是单层 RGB 烘焙画面，山石、枝叶、屋檐等相互叠加。对象边缘是初步分割，**部分保留背景碎片或存在不完整轮廓**，请通过 `preview-transparent-reconstruction.jpg` 查看。没有解决的部分包括干净地面、地贴、树木、厢房、花坛、井栏、池水和更多山石等；提取效果较差的花坛与井栏已主动从包中排除。院墙区域的四个前景石灯仍与墙重叠，需后续进一步修正。

该包是 **对位和 Alpha 检查草稿**，不代表已完成清单，也不代表可通过 Codex 的对象行走/遮挡验收。`placement.json` 中 `x/baseY` 是参照图像基座的估计点，不是程序碰撞参数。

本轮只使用当前潇湘馆庭院母图，不将其他版本的月洞门或重复建筑放进压缩包。门洞已按透明区域抠空；若需要“曲径”题字，请在确认的统一母版上修正后再切分，不混用别处不同画风的门。
