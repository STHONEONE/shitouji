# 潇湘馆内室｜透明素材第一批（待验收）

该 ZIP 提供 15 件单独裁切的美术对象，逐件输出 RGBA PNG 与无损透明 WebP，附 `placement.json`。
每件保留来源插画的原始像素比例，无缩放和无更换家具造型。图片没有背景棋盘格、说明标签或实色底板；`preview-checkerboard.jpg` 仅为合成预览。

**来源限制**：本次使用本次会话中已有的 1672×941《中式书房暖阳雅室.png》作为视觉母版，**不是**从用户仓库的 `assets/scenes/xiaoxiang/references/xiaoxiang-indoor-wide.png` 读取。两图是否完全相同未验证。定位坐标仅适用于这张母版。

**交付状态**：草稿，可供人工美术审阅和独立精灵测试；不宣称已通过 Codex 的运行时碰撞、遮挡、逐对象检查。屏风右缘原图有植物遮挡，书案与座椅、桌腿等交叠部分存在需要人工修补的内容。不能把这批直接当作所有场景的正式分层完成版。

**本批包含**：蓝白床帐、书柜、屏风、琴桌、琴凳、书案、书椅、茶桌、三张独立茶凳、青花盆栽、两扇入口门、独立立灯。

**尚未包含**：完整纯地面、地毯地贴、四面及入口左右墙体等；这些被原 RGB 成图家具覆盖，不能直接通过通道转换补齐，必须重绘或以无家具的参考源重新制作。

`placement.json` 采用当前母版左上角为 (0,0) 的坐标体系。`x/baseY` 是基座底部中央的估计世界坐标，座具含 `seat_world` 和相对图片的 `seat_px`。`base_rect` 是估计基座矩形，不是碰撞框最终数值；需要在引擎里重新核对。

验收重点：人物高度、前后遮挡、床边透明、茶桌桌腿、屏风右缘、原墙体缺口、像素对位。非透明预览图不得作为正式游戏资源。
