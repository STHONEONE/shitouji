# 人物往来：实现范围与原著出处

## 当前范围

10位NPC：宝玉、宝钗、袭人常驻；湘云、探春、惜春、熙凤、妙玉、贾母、王夫人按循环春日作息出访。作息是游戏编排，不是原著某日真实日程。玩家仍为黛玉。三层话题都可随时选择，相处时间只增添细节；没有好感条。

每人两段小事可相谈、在相关物件调查、静听收录或坐读推进时辰；人不在时从手札“人物往来与补读”翻看。当前为原著摘句和情境转述互动，不是把不同章回的原场面搬到当前三月、三处住所重演。
