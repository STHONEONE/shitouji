## 建议规范

- 活跃目录/文件使用英文小写ASCII、数字和连字符；扩展名保留。Python工具遵循snake_case。标准自动识别文件`AGENTS.md`、`README.md`保留原名；HANDOFF.md暂保留兼容入口。
- 角色用固定拼音ID：daiyu/baoyu/baochai/xiren/xiangyun/tanchun/xichun/xifeng/miaoyu/jiamu/wangfuren；住所用xiaoxiang/yihong/hengwu。
- 正式素材归`assets/scenes/<住所>/...`、`assets/characters/<角色>/...`；当前内室所有正在使用的单件从incoming和中文素材目录集中到`assets/scenes/xiaoxiang/indoor/textures/`。已使用素材即使原目录叫draft也不能随整目录归档。
- 原始交图和母图归`art-source/`，派生交付包归`exports/`，文档归`docs/`，构建/素材制作工具归`tools/build/`，浏览器验收脚本归`tools/qa/`，验收结果/截图归`reports/`。
- 正式运行资源按用途命名，不携带v1/v2/新/最终等版本词；历史版本移至_archive或来源记录。原件交付批次用YYYYMMDD。feature模块01—21序号属于加载顺序，保留。
- `_archive/YYYYMMDD/<原相对路径>`保留旧名供恢复；不把归档里的旧名当作活跃命名不规范继续改动。
- U01入口和U02项目根目录默认保留。UUID或身份未确认的原件默认不改名，待用户命名。下面列出的待定文件只提供可选路径，默认先保留。

1. `work/build-spring.py`的root推导（移到tools/build后不能仍使用parent.parent）、模块import、模板/源码/素材/输出路径。
2. 内室scene.json、NPC art.json、所有准备脚本和全局scene-art-contract.json中真实file字段；只替换已确认存在的路径，不能借整理改写美术验收状态。
3. 文档Markdown图片和链接、JSON相对图片路径、人物动作预览HTML及导出包manifest；移动后相对路径需重新计算，不能盲目保留失效文本或换成绝对磁盘路径。
4. QA脚本中的工作根目录、file URL、结果/截图输出位置；工具搬层级后的__dirname/parents也要调整。
5. 当前发布HTML实际内嵌资源，不存在可简单替换的外部图片URL。更新构建源后重建同一入口，逐键核对图像SHA和场景/人物数据保持一致；保持SAVE_KEY及原入口路径。元数据中旧源路径如需更新也应随构建同步。
6. 原始交付ZIP默认不改内部内容，避免破坏来源原件；活跃导出包若获准改名，内部manifest/preview也需重写并重新打包，再核对与散文件一致。

“相对路径不变”按保留相对引用方式、保持当前入口位置理解。文件真正移动后引用字面值必然随位置更新；不能同时承诺移动路径又让原相对路径字面值完全不变。U01/U02未确认前不变更。
