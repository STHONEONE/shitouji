# 其他场景补图要求（可直接交给 GPT 美术助手）

这次只把已确认场景交成可用于游戏的透明分层素材，不改构图、布局、配色、视角和家具设计，不新增装饰。潇湘馆内室另行先做；以下是其他场景的交付要求。各场景分批交，不必一次做完。

## 每批共用要求

1. 使用透明背景 PNG（RGBA）或无损 WebP，物件轮廓外须真正透明；不要白底、黑底、棋盘格背景、文字标题、标签、边框。仅把文件格式改成 RGBA 不算完成。
2. 交一张干净地面：移除直立物件后补全被遮住的地板、草地和道路，不能留下家具残影、空洞或家具阴影。地面内部可以实色，场景范围外透明。
3. 地毯、落花、矮草、贴地小花单独交透明地贴，不能粘在桌椅等物件上。
4. 每个直立物件单独交完整透明 PNG。树与附着在树根处的小草、墙与自带墙脚草保持整体，不拆树冠、树干、屋顶、墙身。物件里不能夹带可行走的地板或道路；门洞内部须透明。
5. 桌子与凳子分开，每只凳子单独导出；书案与书椅分开。案上文房和桌上茶具可跟桌子一起。座具标明坐面位置；床标明躺卧区域。
6. 保持参考图原始像素尺度和微倾俯视角，不旋转、不斜贴、不非等比拉伸、不为凑统一尺寸压缩物件。单件画布按物件原像素包围框裁切，可留少量透明边。
7. 另交一张完整合成预览用于对位，预览不作为运行时贴图。最好附每件在参考图中的左上坐标和基座底部位置；游戏世界坐标、碰撞框和排序由 Codex 接入时确定，不要求美术助手猜程序数据。
8. 清单只覆盖参考图里已经存在的物件：没有的不要新增；相同且尺寸、朝向一致的物件可共用一份。已有合格透明素材先复用，不必重画。
