## 共同要求

- 透明背景 PNG；不要纸底、图鉴边框、说明文字、地面底板或烘焙的大投影。
- 保留当前游戏的俯视前剖视角、暖木色与自然色调，避免改成菱形等距视角。
- 每件单独一张；完整保留花叶、衣袖、底座，四周留透明边距。
- 提供原始清晰素材，避免将旧的小图直接插值放大。
- 物件以底部中心对齐；表情头像五张使用统一画布和脸部位置。
- 若要把花坛的“松土后”状态单独作图，可另交同尺寸花坛状态图，位置和轮廓保持一致；不需要扩展场景。

这些是素材替换需求，不是扩园或新增人物需求。当前代码已分离显示素材与碰撞／交互数据，收到素材后可以只替换对应物件。
