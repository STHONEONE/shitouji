- `其他住所对照/` 中附怡红院、蘅芜苑当前室内成图，均为 1672×941，仅用于对照。

- 等比处理，不横向或纵向单独拉伸，不柔焦。完整效果图与分层素材尽量使用同一画布并保持位置对齐，方便接入。
